Make it yours

Configure in settings.json

Everything lives under the quickrunner.* namespace. Map any language to any compiler or runtime, set your working directory, and control output behaviour.

Tokens like $fileName, $dir and $workspaceRoot keep commands portable.

// settings.json
{
  "quickrunner.clearPreviousOutput": true,
  "quickrunner.showExecutionMessage": false,
  "quickrunner.executorMap": {
    "python": "python -u \"$fileName\"",
    "go": "go run"
  }
}
