# Change Log

All notable changes to the "Quick Runner" extension will be documented in this file.

## [0.12.4]

- Updated configuration and settings namespace from `quick-runner.*` to `quickrunner.*`.
- Standardized extension command IDs to `quickrunner.*` (`quickrunner.run`, `quickrunner.stop`, `quickrunner.runCustomCommand`, `quickrunner.runByLanguage`).
- Renamed syntax grammar to `quickrunner-output.tmLanguage` with matching scopes.
- Added project landing page (`index.html`).
- Updated repository URLs, issue templates, and documentation.

## [0.12.3]

- Updated display name to "Quick Code Runner" for Marketplace publishing.
- Optimized extension icon to 256x256 pixels for high-DPI and Marketplace compliance.
- Upgraded GitHub Actions to Node 24 runtime.

## [0.12.2]

- Rebranded to Quick Runner with the `quickrunner.*` settings namespace.
- Added native support for modern C++20 and Python execution configurations.
- Streamlined architecture, removed legacy external telemetry trackers.
- Full support for 50+ programming languages.
